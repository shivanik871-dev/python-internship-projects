# Python Internship Projects

3 beginner-friendly Python CLI projects built for internship practice.

## 📁 Projects

### 1. Simple Calculator - `calculator.py`
Menu-driven calculator with separate functions for add, subtract, multiply, divide.
Features input validation and divide-by-zero handling.

### 2. Number Guessing Game - `guessing_game.py`
Guess the random number with higher/lower hints.
Features difficulty levels (Easy/Medium/Hard), replay option & best score tracking.

### 3. To-Do List Manager - `todo.py`
Menu-driven task manager with JSON persistence.
Features add/view/mark done/delete, tags & due dates.

## ▶️ How to Run
```bash
python calculator.py
python guessing_game.py
python todo.py
